# 产品边界

## 平台

Android 16 / API 36 起，主要面向平板。个人项目包名为 `de.xianmu.arotation`。
Java + Android SDK 原生 View，无第三方运行库。

## 使用场景

用户希望自行决定横竖屏，尤其是在躺卧、移动设备时，不让姿态变化触发意外旋转。
一枚可拖动按钮和一页设置即可完成任务。

## 交互

- 轻点旋转，按住拖动；长按不跳转，长按后松手不点击。
- 自动贴边、闲置淡出和胶囊收起；收起状态仍一次轻点直接旋转。
- 横竖位置独立保存；正常停用恢复先前的系统旋转设置。
- 设置入口在桌面图标、快捷开关长按和通知内，不占用悬浮按钮的手势。
- 六款 Tabler 图标，沿用 Radix Colors 色阶，不自绘图标、不自行调配色值。

## 不做

不添加账号、网络、广告、统计、无障碍服务、开机自启或保活轮询。
不自动修改全局省电模式，不承诺绕过所有厂商的后台限制或固定方向应用。
