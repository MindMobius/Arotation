# 产品边界

## 平台

Android 16 / API 36 起，主要面向平板。个人项目包名为 `de.xianmu.arotation`。
Java + Android SDK 原生 View，无第三方运行库。

## 使用场景

用户希望自行决定横竖屏，尤其是在躺卧、移动设备时，不让姿态变化触发意外旋转。
平板屏幕大，全面屏手势在横屏时又离手较远；返回、桌面和最近任务这些高频动作同样需要一个顺手的位置。
一枚可拖动的悬浮球、一组可选快捷操作和一页设置即可完成任务。

## 交互

- 轻点小圆点展开半圆扇形菜单，点按动作后自动收起；不区分单个或多个动作，没有特例。
- 快捷操作共四项：旋转、返回、桌面、最近任务。选项在设置页里开关，至少保留一个。
- 小圆点固定显示一个细圆环；桌面图标也是同一枚圆点，动作键各用自己语义的原生 Tabler 字形，都不提供更换。
- 旋转和桌面不需要额外权限：桌面就是普通的 Home 启动。
- 返回和最近任务由一个最小化无障碍服务执行，需要用户在系统设置中手动开启；
  该服务不读取屏幕内容、不截图、不注入手势。
- 自动贴边和闲置渐隐：按钮不会自动收起或隐藏，始终保留完整触摸目标。
- 横竖位置独立保存；正常停用恢复先前的系统旋转设置。
- 设置入口在桌面图标、快捷开关长按和通知内，不占用悬浮按钮的手势。
- 桌面 Logo 与悬浮点共用同一枚圆环标识；动作图标沿用 Tabler 原始素材与 Radix Colors 色阶，不自绘图标、不自行调配色值。
