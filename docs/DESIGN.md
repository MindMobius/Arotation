# Arotation · 0.5.0-preview.3
## Direction
单列原生偏好设置，最大宽度 600dp；不延续上一版营销式双栏布局。
只保留应用名、功能开关、权限动作和直接控制项。无副标题、口号、大预览、页脚卖点。
主界面：悬浮按钮、大小、闲置透明度、自动贴边。没有图标选择区：桌面 Logo、悬浮点与动作图标都是固定的。
悬浮开关下增加“添加快捷开关”和“后台运行”两枚轻量文字入口，沿用 Blue 11。
后台引导按需展示，状态从系统读取；全局省电入口只在实际开启时显示。
外观设置之后是“快捷操作”：四个带各自原生 Tabler 图标的开关、一句行为说明，以及按需出现的系统导航状态行。
横屏方向、重置位置、使用方法、通知和素材许可放在更多菜单。
## Sourced visual system
Radix Colors 的 Slate / Blue；错误使用 Red。原值不调色，完整色阶和固定来源见 third_party/。
Slate 1 背景、Slate 12 正文、Slate 11 次级、Slate 6 分隔；Blue 3 选中底，Blue 11 操作与图形。
小号选中文字在浅色用 Blue 12，在深色用 Blue 11，以保持正文对比度。
Tabler Icons 原始 path / 24px viewport / 2px round strokes。无需自行绘制符号，不混用图标库。
字体使用 Android 原生字体；触摸目标至少 48dp，间距 8dp。符号与文字统一使用原生控件状态。
## Behavior
桌面 Logo 固定为圆点：`MainActivity` 直接作为唯一 launcher 入口，没有 alias，也没有图标切换。
adaptive icon 是 Slate 12 底加 Slate 1 圆环，和悬浮点同一标识；动作键各自使用固定 Tabler 字形。
快捷开关沿用用户所选 Tabler 图标，显示真实服务状态；配色和触摸反馈由 SystemUI 负责。
轻点小圆点始终展开扇形菜单：动作键沿半圆分布，圆心是圆点、弧朝屏幕内侧，步进 60° 并以朝向
内侧的轴线对称——1 个动作居中，2 个 ±30°，3 个 ±60°，4 个 ±90°。按住拖动；
悬浮按钮不提供长按设置，长时间按住再松手不执行动作，多指或取消不补发点击。
小圆点固定显示一个细圆环，像 iOS 辅助触控点，不随动作数量变化；每个动作键固定使用
自己的原生 Tabler 字形：旋转、返回箭头、主页、应用网格。
展开时圆点左右不移动，只在贴近上下边缘时纵向微调，保证整片扇形落在系统栏内；
每个动作键从圆点扩散浮现：52dp 圆形键、键心距圆点 球半径 + 10dp + 键半径、
200ms 缓出、缩放 0.4→1 同时淡入；收起时 140ms 收回圆点。
打开时不进入闲置淡出，闲置 5 秒按无障碍建议时长收起。
点按动作后菜单立即收起并执行；再次轻点悬浮球、拖动、锁屏、转屏都会收起菜单。
未开启系统导航时，返回和最近任务只给出提示，不排队执行；旋转和桌面不受此限制。
旋转、明暗主题或偏好变化时先取消所有在途动画并重建位置，旧坐标不会写回，圆点不会丢失。
闲置只把透明度降到设定值，不改尺寸、不隐藏、不变成胶囊；按钮始终是完整触摸目标。
按下在原位提亮，拖动时窗口直接跟随手指；松手贴边用 220ms 缓出，无弹簧回弹。按住期间不淡出，遵循系统动画开关与无障碍超时。
没有新增循环动画、后台轮询或视觉设置项。其他设置入口与恢复系统旋转行为不变。
