## 本版内容

- 桌面 Logo 与悬浮点是同一枚小圆点（Slate 12 底 + Slate 1 圆环）；`MainActivity` 是唯一 launcher 入口。
- 轻点小圆点展开半圆扇形菜单，键距按数量自适应，朝屏幕内侧排布；点动作后立即收回。
- 四个快捷操作各用原生 Tabler 图标：旋转、返回、桌面、最近任务。
- 自动贴边与闲置渐隐；不提供自动收起，按钮始终保留完整触摸目标。
- 旋转与桌面不需要额外权限；返回和最近任务使用最小无障碍服务（四个能力位全为 false）。

## 设备与覆盖

独立 AOSP Android 16 / API 36 x86_64 平板模拟器，1600×1000、200 dpi。

- 扇形几何（同一圆周、朝屏幕内侧）、从扇形执行旋转、旋转后圆点仍在可见范围内。
- 唯一 launcher 入口、四个动作各保留可解析的原生图标。
- 桌面在无障碍服务被抑制时仍能回启动器；开启服务后返回与最近任务派发成功。
- 拖动、贴边、横竖位置记忆、闲置只改变透明度、锁屏隐藏、权限撤回、通知与快捷开关回归。

## 边界

系统在设置、无障碍与权限界面会主动隐藏非系统浮层，小圆点在这些界面不可见，属于平台策略。
返回和最近任务仍然需要用户手动开启系统导航服务；这是 Android 没有公开替代 API 的部分。
本版没有在机主实际平板上验证厂商后台策略、触感与长期稳定性；大字号与窄屏截图留到后续版本复查。
