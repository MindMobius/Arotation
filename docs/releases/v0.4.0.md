## 设备与覆盖

独立 AOSP Android 16 / API 36 x86_64 平板模拟器，1600×1000、200 dpi，开启手势导航。

- 真实横竖切换、停止恢复、系统自动旋转优先、权限撤回处理。
- 拖动、左右贴边、三种大小、收起状态一次点击、长按后拖动及松手不误触。
- 多指打断、取消、无动画模式、长时间按住不自动收起。
- 控件可见区域可从左右边缘拖出；控件之外的返回手势仍正常。
- 六款图标及唯一 launcher alias、通知设置/停用、锁屏隐藏与解锁恢复。
- 真实系统快捷开关添加、启停、长按设置、缺少授权时的引导。
- 实际电池页面选择不受限制、返回后刷新状态、系统省电入口、PIN 认证后启动。
- 浅/深色界面与横/竖屏截图来自 Android 模拟器，不是浏览器仿图。

## 边界

`check-startup.py --release` 明确跳过需要 `run-as` 的进程结束、冷进程启动和 sticky 进程重建检查，不把这些未执行项目计为通过。
测试没有连接用户的实际平板；厂商后台管理、系统升级后的行为与真实触摸手感仍需实机使用。
GitHub CI 负责独立环境下的调试构建、Lint、算法和素材检查，不伪称执行过设备测试。
